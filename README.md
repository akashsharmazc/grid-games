# 🎮 Grid Games

A lightweight React 18 app with grid-based games, smooth animations, and multiple themes.

)

## Features

- **Free Grid** – Toggle cells freely (3×3 up to 8×8)  
- **Tic-Tac-Toe** – Classic 3×3 with win detection & highlights  
- **Pattern Memory** – Watch and repeat patterns, difficulty scales  

### Design & UX
- 4 themes: Light, Dark, Playful, High-Contrast  
- Animated backgrounds & glassy UI  
- Undo/Redo (Ctrl+Z / Ctrl+Y)  
- Auto-save to localStorage  
- Share game state via URL  
- Keyboard navigation & accessibility support  

### Tech Stack
- React 18 + TypeScript  
- Tailwind CSS v3  
- Vite for fast builds  
- Local state via custom hooks
